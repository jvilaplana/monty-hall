Per què convé canviar?

El raonament

  1. Quan tries, la teva porta té el premi amb probabilitat 1/3. Les altres dues, juntes, 2/3.
  2. El presentador sap on és el premi i sempre obre una porta amb cabra. Això no aporta cap informació sobre la teva porta: continua tenint 1/3.
  3. Els 2/3 de les altres dues portes es concentren ara en l'única que queda tancada.

Mantenir: 1/3 ≈ 33 % · Canviar: 2/3 ≈ 67 %

Generalitzacions

N portes (el presentador n'obre N − 2 amb cabra): mantenir guanya amb 1/N, canviar amb (N − 1)/N. Amb 100 portes, canviar guanya el 99 % de les vegades.

Presentador que obre a l'atzar: si per casualitat surt cabra, les dues portes tancades són igual de probables: P(premi a la teva | cabra) = (1/3) / (2/3) = 1/2. Canviar ja no ajuda.

I a la pràctica?

Si jugues moltes partides, el percentatge d'encerts de cada estratègia s'acosta a la probabilitat teòrica (llei dels grans nombres):

% encerts = partides guanyades ÷ partides jugades → probabilitat

Al joc següent, la columna Teòric mostra el valor esperat per comparar-lo amb els teus resultats.
